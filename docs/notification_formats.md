# These are all of the different notification formats sent out by the carreer-hub

## Email Notifications

### New Job Notification
Subject: 🚀 New Job For You: {Job Title} at {Company Name}
Header: Company Logo + Name
Body: {
	{Job Title} {Match Score}
	{Location}
	{Date Posted}
	{Company} just posted a job opportunity that matches your interests!
}
Call To Action Button: [Click Here to Apply Now!]
Footer: You are receiving this message because you have subscribed to receiving notifications for {Company Name}. No longer interested? [unsubscribe]

### Closing Job Notification
Subject: 🚨 Application Closing Soon For: {Job Title} at {Company Name}
Header: Company Logo + Name
Body: {
	{Job Title}
	{Location}
	{Company} will soon be closing applications for this position.
}
Call to Action Button: [Click Here to Apply Now!]
Footer: You are receiving this message because you have subscribed to receiving notifications for {Company Name}. No longer interested? [unsubscribe]
