# CS Career Hub

Centralized job and internship hub for CS students: aggregated postings, match scores, application tracking, and skill trends.

## Project structure

```txt
cs-career-hub/
  frontend/   Next.js + React + TypeScript frontend
  backend/    Placeholder for backend/API work owned by the backend team
  docs/       Shared project docs and database planning
```

## Frontend

The current implementation is frontend-only and lives in `frontend/`.

```bash
cd frontend
npm install
npm run dev
```

Open `http://localhost:3000` after the dev server starts.

## Backend

No backend code has been added. The `backend/` folder is only reserved so the repo has a clear place for the backend team later.
