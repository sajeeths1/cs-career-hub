# Frontend

Next.js + React + TypeScript frontend for CS Career Hub.

## Stack

- Next.js + React
- TypeScript
- Tailwind CSS
- shadcn-style local UI components
- Lucide React icons
- React Hook Form + Zod

## Commands

```bash
npm install
npm run dev
npm run lint
npm run build
```

The resume upload is a frontend-only preview. Files are not sent to a server.
